# Инструкция: запуск и ведение сайта

Названия кнопок в GitHub, Vercel и Google могут чуть отличаться, смысл тот же.

## Шаг 1. Новый токен бота (5 минут, делать первым)
1. Telegram → @BotFather → команда `/revoke` → выберите своего бота. Старый токен перестанет работать.
2. BotFather пришлёт новый токен. Скопируйте его, никому не показывайте и в код не вставляйте.
3. Vercel → ваш проект → Settings → Environment Variables. Добавьте две переменные (Environments: все галочки):
   - `TG_BOT_TOKEN` = новый токен
   - `TG_CHAT_ID` = ваш числовой id чата (тот, что работал раньше)
4. Нажмите Save. Redeploy сделаем после загрузки файлов.

## Шаг 2. Загрузка файлов на GitHub (лучше с компьютера)
1. Распакуйте `TECHCNSHOPKZ-public.zip`.
2. GitHub → репозиторий TECHCNSHOPKZ. Удалите старые лишние файлы: откройте `kitai-flagmany.zip` и `netlify.toml` → значок корзины → Commit changes.
3. Add file → Upload files. Перетащите всё содержимое распакованной папки, включая папки `api` и `img`. Нужно загрузить: `index.html`, `og.png`, `apple-touch-icon.png`, `README.md`, `.gitignore`, `stock-template.csv`, папки `api` и `img`.
4. Внизу нажмите Commit changes. Vercel сам пересоберёт сайт (около минуты).
5. Если сайт просит вход или пишет 401: Vercel → Settings → Deployment Protection → отключите защиту для Production.

## Шаг 3. Таблица наличия
1. Откройте sheets.google.com → Пустая таблица.
2. Файл → Импорт → Загрузка → выберите `stock-template.csv` → «Заменить таблицу» → Импортировать данные.
3. Файл → Поделиться → Опубликовать в интернете. Слева «Весь документ» замените на нужный лист, справа вместо «Веб-страница» выберите **Значения, разделённые запятыми (.csv)** → Опубликовать → скопируйте ссылку.
4. Vercel → Settings → Environment Variables → добавьте `STOCK_CSV_URL` = эта ссылка → Save.
5. Vercel → Deployments → у последнего деплоя меню «...» → Redeploy.
6. Таблица открыта по ссылке: не пишите в ней ничего личного.

## Шаг 4. Как вести наличие каждый день
- Столбцы A и B (id и название) не трогайте.
- Столбец C «Статус»: `в наличии`, `под заказ` или `нет`.
- Столбец D «Комментарий»: что именно есть, например `чёрный 12/256, серый 16/512`. Показывается на сайте.
- Сайт обновляется за 1–5 минут. Меняется метка на карточке: «В наличии в Петропавловске», «Под заказ» или «Нет в наличии» (кнопка заказа выключается).

## Шаг 5. Проверка перед запуском
1. Откройте сайт с телефона: фото грузятся, цены на месте.
2. Оформите тестовый заказ со своим контактом. В Telegram должно прийти сообщение «НОВЫЙ ЗАКАЗ С САЙТА».
3. Поменяйте статус модели в таблице, через 5 минут обновите сайт: метка должна измениться.
4. Откройте сайт с `#admin` в конце адреса: ничего (админки в публичной версии нет).

## Если что-то не работает
- Заявка не приходит: проверьте `TG_BOT_TOKEN` и `TG_CHAT_ID`, затем Redeploy. Сначала напишите своему боту любое сообщение, иначе бот не сможет писать вам.
- Наличие не меняется: ссылка должна быть в формате CSV и начинаться с docs.google.com, после смены переменной нужен Redeploy.
- Покупатели всё равно могут написать в Telegram: кнопка «Открыть Telegram» работает без бота.

## Как менять цены и добавлять модели
Сайт хранит готовые цены. Для изменения курса, наценки или новых моделей пришлите Claude файл `PRIVATE-index.html` и новые данные. Этот файл содержит закупку, в GitHub его не загружайте.
