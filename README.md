# TechCNShopKZ

Статический сайт + функции Vercel: `/api/order` (заявки в Telegram) и `/api/stock` (наличие из Google Таблицы).
Здесь лежит только публичная версия: закупочных цен и админки в ней нет.

## Переменные окружения (Vercel → Settings → Environment Variables)
- `TG_BOT_TOKEN`: токен бота от @BotFather (в коде его быть не должно)
- `TG_CHAT_ID`: id чата, куда приходят заявки
- `STOCK_CSV_URL`: ссылка на опубликованную таблицу наличия (см. ниже)

После изменения переменных нужен Redeploy.

## Наличие без правки кода
1. Google Таблицы → Файл → Импорт → загрузите `stock-template.csv` → «Заменить таблицу».
2. Файл → Поделиться → Опубликовать в интернете → выберите лист и формат **CSV** → Опубликовать → скопируйте ссылку.
3. Вставьте её в Vercel как `STOCK_CSV_URL` и сделайте Redeploy.
4. Дальше правите только колонку C («Статус») и D («Комментарий») прямо с телефона. Значения: `в наличии`, `под заказ`, `нет`. Сайт обновится в течение 1–5 минут.
Первые два столбца (id и название) не меняйте. В опубликованной таблице не храните ничего личного: она открыта по ссылке.

## Изменение цен
Цены посчитаны заранее. Чтобы поменять курс, наценку или добавить модель, нужен приватный файл `PRIVATE-index.html` (хранить у себя, в GitHub не загружать) и пересборка публичной версии.

## Аналитика
События: `checkout_open`, `order_submit`, `order_telegram`, `order_form_error` (GoatCounter, Яндекс.Метрика или Plausible, если подключены).
